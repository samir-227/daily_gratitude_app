# أثر (Athar)

كل امتنان... أثر. تطبيق امتنان يومي يساعدك تسجّل اللحظات الصغيرة اللي بتشكر عليها — بصوتك أو بكتابتك، في ثواني. مبني بـ Flutter باستخدام Clean Architecture و Cubit.

## المميزات

### 🌟 شاشة البداية
- **أنيميشن مخصص** — logo مرسوم بـ CustomPainter مع ripple effect وظهور تدريجي للنص.
- **توجيه ذكي** — يتجه لشاشة الترحيب لأول مرة أو الرئيسية مباشرة بعد ذلك.

### 👋 الترحيب
- **٣ شاشات تعريفية** — ترحيب، شرح الفكرة، وتحديد وقت التذكير اليومي.
- **مرة واحدة فقط** — يظهر في أول استخدام فقط.

### 🎙️ التسجيل الصوتي
- **تسجيل بصوتك** — سجّل لحظات الامتنان بضغطة واحدة. جودة WAV 16kHz.
- **تحويل الصوت لنص عربي (STT)** — على الجهاز بالكامل (مش محتاج API key) بيكتشف العربية تلقائيًا.
- **تعديل النص** — صحّح أي خطأ في التفريغ قبل الحفظ.
- **المشاعر** — اختر شعورك من ٦ مشاعر: ممتن (Grateful)، مبسوط (Happy)، هادي (Calm)، محبوب (Loved)، ثابت (Grounded)، متأمل (Reflective).
- **استخراج الكلمات المفتاحية** — تُستخرج تلقائيًا من النص العربي مع إزالة التشكيل والكلمات الشائعة.

### 🏠 الشاشة الرئيسية
- **الأيام المتتالية** — عرض عدد الأيام المتتالية مع أيقونة وإحصائيات سريعة.
- **بطاقة النهارده** — أول ٦٠ حرف من تسجيل النهارده، تقدر تضغط عشان تفتحه كاملًا.
- **كاروسيل اللحظات الأخيرة** — تصفّح آخر اللحظات بسرعة.
- **بطاقة التأمل** — اقتباس أو تذكير يومي.
- **اختصار التسجيل السريع** — زر لتسجيل لحظة بالتنفس السريع.

### 📖 تفاصيل اللحظة
- **نص كامل** — عرض اللحظة في بطاقة مرتبة.
- **مشغل صوت** — play/pause و seek مع شريط التقدم.
- **المشاعر والمواضيع** — عرض المزاج والكلمات المفتاحية المرتبطة.

### 📅 الجدول الزمني
- **تصفّح كل اللحظات** — من الأحدث للأقدم مع تجميع حسب التاريخ.
- **تصفية** — كل اللحظات، الأسبوع ده، أو الشهر ده.
- **بحث** — ابحث في نصوص اللحظات.
- **تشغيل الصوت** — شغّل الصوت مباشرة من الجدول. لحظة واحدة بتشتغل في كل مرة.
- **تعديل وحذف** — مع تأكيد قبل الحذف.

### 📊 الإحصائيات
- **نشاطك الأسبوعي** — رسم بياني بعدد اللحظات كل يوم لآخر ٧ أيام.
- **إحصائيات سريعة** — الأيام المتتالية الحالية، أطول عدد أيام، إجمالي اللحظات.
- **المواضيع الأكثر تكرارًا** — الكلمات المفتاحية الأكثر ظهورًا.
- **توزيع المشاعر** — النسبة المئوية لكل مزاج.

### 🏆 إنجازات الاستمرارية
- **احتفالات** — عند إتمام ٣ و ٧ و ١٤ و ٣٠ و ٦٠ و ١٠٠ يوم متتالي تظهر رسالة احتفالية متحركة.

### ⚙️ الإعدادات
- **الوضع الليلي** — تبديل بين الثيم الفاتح والداكن.
- **تذكير يومي** — تشغيل/إيقاف مع تحديد الوقت المناسب.
- **حالة العربية** — عرض حالة اكتشاف اللغة في الـ STT.
- **تصدير البيانات** — تصدير كل اللحظات كملف .txt ومشاركته.
- **مسح كل البيانات** — مسح جميع اللحظات والملفات الصوتية والإحصائيات.

## قواعد البنية

- **Cubit فقط** — مفيش Riverpod أو Provider أو GetX. `setState` فقط لحالات UI المحلية.
- **Domain layer نظيف** — مفيش `package:flutter/` في ملفات `domain/`.
- **مفيش code generation** — Dart 3 sealed classes, records, switch expressions بدل Freezed/build_runner.
- **معالجة الأخطاء** — cubits بتستخدم try/catch وتبعث error states. مفيش raw exceptions.
- **كل حاجة Cupertino** — ممنوع استخدام Material widgets.
- **RTL دائمًا** — التطبيق بالكامل في `Directionality(textDirection: TextDirection.rtl)`.

## تدفق البيانات

1. **🎙️ سجّل** → AudioService يسجل WAV + SpeechService يحوله لنص عربي → Cubit بيحتفظ بالنص والمسار
2. **💾 احفظ** → UUID بيتولد → ملف الصوت بيتنقل للتخزين الدائم → اللحظة بتتسجل في Hive → الإحصائيات بتتحدث
3. **👁️ شوف** → اللحظة بتتنقل من Hive → النص كامل بيتعرض → الصوت بيتشغل مع play/pause/seek
4. **📊 حلّل** → كل اللحظات بتتجب من Hive → النشاط الأسبوعي، المواضيع، المشاعر بتتحسب
